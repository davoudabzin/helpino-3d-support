# Helpino 24: Seamless Customer Experience

یک صفحه اصلی (Homepage) کاملاً حرفه‌ای، مدرن، سه‌بعدی و تعاملی برای برند «هلپینو ۲۴» طراحی کن؛ با تمرکز اصلی بر «مرکز تماس و پشتیبانی حرفه‌ای» و با هدف تبدیل بازدیدکننده به مشتری.

نام برند:
هلپینو ۲۴ | Helpino 24

موضوع اصلی صفحه:
مرکز تماس، پشتیبانی تلفنی، پشتیبانی آنلاین و پشتیبانی فنی برای کسب‌وکارها و کاربران

هدف طراحی:
ایجاد یک Homepage سطح بالا با ظاهر Premium و تکنولوژی‌محور که در نگاه اول مفهوم «پشتیبانی ۲۴ ساعته، مرکز تماس، پاسخگویی سریع، نیروی متخصص و خدمات دیجیتال» را منتقل کند.

سبک بصری:
- طراحی کاملاً سه‌بعدی (3D)
- Modern / Premium / Futuristic
- استفاده از 3D Glassmorphism
- استفاده از عناصر Floating و Depth
- نورپردازی سینمایی و واقع‌گرایانه
- سایه‌های نرم و طبیعی
- افکت‌های عمق، Parallax و Layered UI
- انیمیشن‌های ظریف و حرفه‌ای
- Micro Interaction روی دکمه‌ها، کارت‌ها و آیکون‌ها
- استفاده از مدل‌های سه‌بعدی مرتبط با مرکز تماس
- استفاده از Headset، مانیتور، لپ‌تاپ، تلفن، داشبورد پشتیبانی، حباب‌های گفتگو، شبکه ارتباطی و عناصر دیجیتال
- از تصاویر کلیشه‌ای Stock استفاده نکن
- تصاویر و المان‌های گرافیکی باید اختصاصی و هماهنگ با هویت بصری برند باشند.

هویت رنگی:
از پالت رنگی لوگوی هلپینو ۲۴ استفاده کن.
رنگ اصلی: آبی حرفه‌ای
رنگ‌های مکمل: سرمه‌ای، سفید، آبی روشن و طیف‌های مناسب برای ایجاد عمق سه‌بعدی
پس‌زمینه‌ها عمدتاً روشن و Premium باشند و در بخش‌های خاص از پس‌زمینه‌های Dark / Navy برای ایجاد Contrast استفاده شود.
